# To-Do List App

Welcome to my To-Do List App. This project is a simple and interactive task management application developed using HTML, CSS, and JavaScript. It allows users to add, complete, and delete tasks while saving the task data in the browser.

## About the Project

This To-Do List application was developed as part of my web development project.

The main purpose of this project is to create a simple task management system where users can organize their daily tasks in an easy and user-friendly interface.

The application demonstrates the use of HTML for creating the structure, CSS for designing the interface, and JavaScript for adding functionality and interactivity.

The project also uses browser Local Storage to save tasks. This allows the tasks to remain available even after refreshing or reopening the webpage.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Store tasks using browser Local Storage
- Tasks remain saved after refreshing the page
- Prevent empty tasks from being added
- Simple and user-friendly interface
- Responsive design for different screen sizes
- Interactive buttons
- Clean and minimal layout

## Technologies Used

- HTML5

How it work

### Adding a Task

The user enters a task in the input box and clicks the **Add** button.

For example:

```text
Complete JavaScript Assignment
```

The task is then displayed in the task list.

### Completing a Task

The user can click on a task to mark it as completed.

The completed task is displayed with a line-through effect to show that the task has been finished.

### Deleting a Task

Each task has a **Delete** button.

When the user clicks the Delete button, the selected task is removed from the task list.

### Local Storage

The application uses the browser's Local Storage to store task information.

The tasks are saved using JavaScript and retrieved when the application is loaded again.

This means that tasks are not lost when the webpage is refreshed.

## Usage

1. Open the To-Do List application.
2. Enter a task in the input field.
3. Click the **Add** button.
4. The task will appear in the task list.
5. Click the task to mark it as completed.
6. Click the **Delete** button to remove a task.
7. Refresh the page to verify that the tasks are saved using Local Storage.
